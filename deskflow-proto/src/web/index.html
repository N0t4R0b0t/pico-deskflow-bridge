Latency is the time a key or mouse event spends in the bridge, from Deskflow to the Bluetooth radio, over the last 64 events. TLS path is the time from the USB network to a decoded message, and inbound backlog is what's queued there; a backlog that keeps growing during long moves means the bridge can't keep up. Packets in the Bluetooth chip should stay at 3 or less; each one waits for those ahead of it. Nothing here covers the server or the laptop.

Clipboard

Copy text on the Mac, move the cursor to the laptop, then press Ctrl+Alt+V (Ctrl+Option+V on a Mac keyboard) or use the button to have the bridge type it into the focused window. Text only, typed for the laptop's keyboard layout (set below); characters it can't type are skipped.
